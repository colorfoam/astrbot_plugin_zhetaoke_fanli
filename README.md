# astrbot_plugin_zhetaoke_fanli — 折淘客全平台返利助手

对接 [折淘客开放平台 API](https://www.zhetaoke.com/one/api3.aspx) 的 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 插件：**美团外卖/闪购、饿了么（淘宝闪购）、淘宝、抖音**的转链、订单同步与佣金返利，支持 **cron 定时推送红包/日报**、会话黑白名单、Markdown 精美排版，并内置 **WebUI 仪表盘**（订单浏览/搜索/统计/用户返利/转链工具/定时推送管理）。

## ✨ 功能一览

### 💬 聊天指令
| 指令 | 说明 |
|---|---|
| `绑定 [编号]` | 绑定返利ID（11位内数字，不填自动分配），订单自动归档 |
| `我的返利` | 查询订单数、佣金合计、预估返利与已结算返利 |
| `查订单` | 查看自己名下最近 10 笔订单（卡片式排版） |
| `美团红包` | 生成带个人返利归因的美团外卖红包链接 |
| `闪购红包` / `饿了么红包` | 生成饿了么/淘宝闪购红包链接 |
| `淘宝转链 [淘口令/链接]` | 淘宝商品高佣转链 |
| `抖音转链 [链接/口令]` | 抖音商品转链 |
| `搜抖音 [关键词]` | 抖音选品搜索（按佣金排序） |
| `同步订单` | 管理员手动触发订单同步 |
| `回溯订单 [天数]` | 管理员回溯历史订单（最多 730 天/两年） |
| `ztk帮助` | 指令帮助 |

### 📦 订单同步与统计
- 定时轮询**美团**（`open_meituan_orderList2`）、**联盟全平台**（`open_lianmeng_orderList`，覆盖淘宝/饿了么/抖音/京东/拼多多等）、**淘宝明细**（`open_dingdanchaxun2`）三类订单接口
- 订单落库 SQLite（自动迁移旧数据），记录实付/佣金/状态/退款/结算
- 启动自动**回溯历史订单**（默认 7 天，可配到 730 天），也可指令手动触发
- 检测到新订单可推送提醒给管理员

### ⏰ 定时推送（cron）
在 AstrBot 面板左侧「插件页面」→「折淘客返利助手」→「⏰ 定时推送」可视化管理：
- **标准 5 字段 cron 表达式**（分 时 日 月 周，支持 `* , - /`），有「每天此时间」快捷生成，任务列表自动显示中文描述（如 `0 9 * * 1-5` → 工作日 09:00）
- **机器人下拉直读 AstrBot 平台实例**：显示你在面板里设置的实例名称、适配器类型，OneBot 平台自动读取登录账号（昵称+QQ号），多机器人一目了然
- **群聊/好友下拉直读 AstrBot 数据**：自动调 OneBot `get_group_list` / `get_friend_list`，选群选人不用手查 ID（也支持手填）
- 推送内容三种：`meituan` 美团红包 / `eleme` 闪购红包 / `orders` 订单日报
- 任务支持**编辑 / 启停 / 删除 / 一键推送一次**（手动立即推送，不用等 cron）
- 每个任务可单独设置返利ID归因；旧配置 `HH:MM|平台:群:ID|类型` 格式自动兼容

### 🎨 消息样式（Markdown）
- 「回复消息样式」三档：`plain` 纯文本 / `markdown` 始终 MD / `auto` 按渠道自动（仅「Markdown 渠道列表」内的平台发 MD）
- 作用于红包文案、定时推送、`查订单` / `我的返利`：标题加粗、链接可点击、订单卡片式排版
- 支持自定义红包文案模板（占位符 `{标题} {描述} {链接} {二维码} {返利ID}`，空值占位符整行自动移除）
- 红包发送方式可选：`both` 文字+二维码图 / `link` 仅链接 / `image` 仅二维码图
- 闪购二维码可选淘宝独立码（外部可扫）或微信小程序码

### 🔐 会话黑白名单
`off` 不过滤 / `blacklist` 黑名单 / `whitelist` 白名单；名单支持群号、QQ号、平台名或完整 UMO。

### 🖥️ WebUI 仪表盘
**主入口（推荐）**：AstrBot 面板左侧「插件页面」→「折淘客返利助手」（基于 AstrBot Plugin Pages，v4.24+），iframe 内嵌、自动携带登录态、跟随亮/暗主题。功能：

- 📊 数据总览：订单数 / 佣金 / 今日新增 / 退款
- 📋 订单查询：平台/状态/日期/关键词筛选 + 分页 + 返利列
- 👥 用户返利：绑定用户佣金与应返金额汇总
- 🔗 转链工具：红包活动与商品转链可直接在页面操作
- ⏰ 定时推送：任务可视化管理（见上）

**备用独立入口**：默认关闭（配置 `web_enabled` 开启），地址 `http://127.0.0.1:17878/`，可选令牌鉴权 `?token=xxx`。旧版 AstrBot（无插件页面支持）请开启。

### 💰 返利逻辑
用户应返金额 = 订单佣金(profit) × `rebate_rate`（默认 30%，可配）；已结算部分按 `settle_profit` 计算。返利归因：美团/饿了么用 `customer_id`、抖音用 `external_info`、淘宝用 `external_id`，均为 11 位内数字，与用户绑定的返利ID一致即归档。

## 📥 安装

1. 将整个 `astrbot_plugin_zhetaoke_fanli` 目录放入 AstrBot 的 `data/plugins/`
2. WebUI 插件管理中安装/重载插件（依赖 aiohttp 会自动装）
3. 在插件配置「折淘客凭据」中填写：
   - `appkey`：折淘客对接秘钥（zhetaoke.com 用户中心获取）
   - `sid`：淘宝账号授权 SID（用户中心「淘宝授权」页面）
   - `pid`：淘宝联盟 PID（`mm_xxx_xxx_xxx`，淘宝转链必填）

## ⚠️ 使用前提

- 必须在折淘客后台完成**淘宝账号授权**获得 SID
- 折淘客订单接口**只返回通过折淘客转链接口产生的订单**（2021-06-18 起规则）
- 折淘客禁止多线程高频调用：轮询间隔请勿低于 2 分钟；淘宝订单接口单次最多查 3 小时
- **定时推送目标平台请选 NapCat（aiocqhttp）等支持主动消息的平台**；qq_official 不支持主动发送
