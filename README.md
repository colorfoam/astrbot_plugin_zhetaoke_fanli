# astrbot_plugin_zhetaoke_fanli — 折淘客全平台返利助手

对接 [折淘客开放平台 API](https://www.zhetaoke.com/one/api3.aspx) 的 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 插件：**美团外卖/闪购、饿了么（淘宝闪购）、淘宝、京东（含京东外卖活动）**的转链、订单同步与佣金返利，支持 **cron 定时推送红包/日报**、会话黑白名单、Markdown 精美排版，并内置 **WebUI 仪表盘**（订单浏览/搜索/统计/用户返利/转链工具/定时推送管理）。

> ⚠️ 抖音转链/搜索功能已移除：抖音官方「抖客平台」关闭，折淘客相关接口（`open_douyin_zhuanlian` / `open_douyin_product_search`）已下线。

## ✨ 功能一览

### 💬 聊天指令
| 指令 | 说明 |
|---|---|
| `绑定 [编号]` | 绑定返利ID（11位内数字，不填自动分配），订单自动归档 |
| `我的返利` | 查询订单数、佣金合计、预估返利与已结算返利 |
| `查订单` | 查看自己名下最近 10 笔订单（卡片式排版） |
| `美团红包` | 生成带个人返利归因的美团外卖红包链接 |
| `闪购红包` / `饿了么红包` | 生成饿了么/淘宝闪购红包链接 |
| `京东红包` / `京东外卖红包` / `京东外卖` | 生成京东外卖红包推广链接（默认用内置京东外卖活动页，可在配置里换成自己的活动链接；也支持 `京东红包 活动链接` 临时指定） |
| `淘宝转链 [淘口令/链接]` | 淘宝商品高佣转链 |
| `京东转链 [链接/口令]` | 京东转链（京粉）：商品/活动链接、短链(3.cn)、口令、SKU ID；京东外卖活动链接同样支持 |
| `同步订单` | 管理员手动触发订单同步 |
| `回溯订单 [天数]` | 管理员回溯历史订单（最多 730 天/两年） |
| `ztk帮助` | 指令帮助 |

### 📦 订单同步与统计
- 定时轮询**美团**（`open_meituan_orderList2`）、**联盟全平台**（`open_lianmeng_orderList`，覆盖淘宝/饿了么/抖音/京东/拼多多等）、**淘宝明细**（`open_dingdanchaxun2`）三类订单接口
- 可选叠加**京东订单明细**（`open_jing_union_openz_order_row_query`，需京东开放平台应用 AppKey/AppSecret），按 1 小时窗口切片回溯，用于京东订单补漏/更实时
- 订单落库 SQLite（自动迁移旧数据），记录实付/佣金/状态/退款/结算
- 启动自动**回溯历史订单**（默认 7 天，可配到 730 天），也可指令手动触发
- 检测到新订单可推送提醒给管理员

### ⏰ 定时推送（cron）
在 AstrBot 面板左侧「插件页面」→「折淘客返利助手」→「⏰ 定时推送」可视化管理：
- **标准 5 字段 cron 表达式**（分 时 日 月 周，支持 `* , - /`），有「每天此时间」快捷生成，任务列表自动显示中文描述（如 `0 9 * * 1-5` → 工作日 09:00）
- **机器人下拉直读 AstrBot 平台实例**：显示你在面板里设置的实例名称、适配器类型，OneBot 平台自动读取登录账号（昵称+QQ号），多机器人一目了然
- **群聊/好友下拉直读 AstrBot 数据**：自动调 OneBot `get_group_list` / `get_friend_list`，选群选人不用手查 ID（也支持手填）
- 推送内容四种：`meituan` 美团红包 / `eleme` 闪购红包 / `jd` 京东红包 / `orders` 订单日报
- 任务支持**编辑 / 启停 / 删除 / 一键推送一次**（手动立即推送，不用等 cron）
- 每个任务可单独设置返利ID归因；旧配置 `HH:MM|平台:群:ID|类型` 格式自动兼容

### 🎨 消息样式（Markdown）
- 「回复消息样式」三档：`plain` 纯文本 / `markdown` 始终 MD / `auto` 按渠道自动（仅「Markdown 渠道列表」内的平台发 MD）
- 作用于红包文案、定时推送、`查订单` / `我的返利`：标题加粗、链接可点击、订单卡片式排版
- 支持自定义红包文案模板（占位符 `{标题} {描述} {链接} {二维码} {返利ID}`，空值占位符整行自动移除）
- 红包发送方式可选：`both` 文字+二维码图 / `link` 仅链接 / `image` 仅二维码图
- 闪购二维码可选淘宝独立码（外部可扫）或微信小程序码

### 🔐 会话黑白名单
`off` 不过滤 / `blacklist` 黑名单 / `whitelist` 白名单；名单支持群号、QQ号、平台名或完整 UMO。

### 🖥️ WebUI 仪表盘
**主入口（推荐）**：AstrBot 面板左侧「插件页面」→「折淘客返利助手」（基于 AstrBot Plugin Pages，v4.24+），iframe 内嵌、自动携带登录态、跟随亮/暗主题。功能：

- 📊 数据总览：订单数 / 佣金 / 今日新增 / 退款
- 📋 订单查询：平台/状态/时间/关键词筛选 + 分页 + 返利列；时间框支持 `2026-09-14`、`20260914`、`202609`（整月）、`2026`（全年）等写法，非法日期自动拦截；另有「不限/今天/昨天/近7天/本月/上月」快捷筛选
- 👥 用户返利：绑定用户佣金与应返金额汇总
- 🔗 转链工具：红包活动（美团/闪购/京东外卖）与商品转链（淘宝/京东）直接在页面操作，结果内嵌二维码预览 + 一键复制；可勾选「二维码转短链」把长链接转成 `t.cn` 短链
- ⏰ 定时推送：任务可视化管理（见上）
- ⚙️ 插件配置：仪表盘内直接改配置（等价于面板配置页），分组卡片 + 两列字段 + 右下角浮动「保存设置」按钮；密钥字段带👁显示切换；管理员/黑白名单可从机器人读群/好友（先选平台→再选群聊/私聊→下拉选或手填）
- 📖 使用说明：聊天指令从插件实际注册的指令表动态生成，永不与代码脱节

**备用独立入口**：默认关闭（配置 `web_enabled` 开启），地址 `http://127.0.0.1:17878/`，可选令牌鉴权 `?token=xxx`。旧版 AstrBot（无插件页面支持）请开启。

### 💰 返利逻辑
用户应返金额 = 订单佣金(profit) × `rebate_rate`（默认 30%，可配）；已结算部分按 `settle_profit` 计算。返利归因：美团/饿了么用 `customer_id`、淘宝用 `external_id`，均为 11 位内数字，与用户绑定的返利ID一致即归档。

## 📥 安装

1. 将整个 `astrbot_plugin_zhetaoke_fanli` 目录放入 AstrBot 的 `data/plugins/`
2. WebUI 插件管理中安装/重载插件（依赖 aiohttp 会自动装）
3. 在插件配置「折淘客凭据」中填写：
   - `appkey`：折淘客对接秘钥（zhetaoke.com 用户中心获取）
   - `sid`：淘宝账号授权 SID（用户中心「淘宝授权」页面）
   - `pid`：淘宝联盟 PID（`mm_xxx_xxx_xxx`，淘宝转链必填）
   - `jd_union_id`：京东联盟ID（纯数字，京东转链必填；union.jd.com「我的联盟信息」获取，需先在折淘客完成授权）
   - `jd_position_id`：京东默认推广位ID（选填，纯数字；用户绑定返利ID时自动用其返利ID归因）
   - `jd_act_url`：京东红包（京东外卖）推广活动链接，留空用内置京东外卖活动页
   - `jd_wechat_type`：京东转链微信小程序短链类型（off=普通短链 / 1=京小街 / 2=京东购物），微信渠道可直开
   - `shorturl_api`：自定义短链 API 模板（选填），支持 `{url}` / `{url_enc}` 占位符，如 `https://api.example.com/s?key=xxx&url={url_enc}`；填了优先用它转短链，失败自动回退折淘客新浪短链（折淘客短链需已填 `sid`）

## ⚠️ 使用前提

- 必须在折淘客后台完成**淘宝账号授权**获得 SID
- 折淘客订单接口**只返回通过折淘客转链接口产生的订单**（2021-06-18 起规则）
- 折淘客禁止多线程高频调用：轮询间隔请勿低于 2 分钟；淘宝订单接口单次最多查 3 小时
- **定时推送目标平台请选 NapCat（aiocqhttp）等支持主动消息的平台**；qq_official 不支持主动发送
- 京东转链需先在**折淘客后台完成京东联盟授权**，否则返回未授权错误
- 京东订单归因：`positionId`（纯数字返利ID，超 11 位或非数字时回退配置的默认推广位）与 `subUnionId`（原样写返利ID）双写，订单接口会透出
- **京东侧接口不返回二维码图片**（不像美团有小程序码、饿了么有独立二维码），因此 `京东红包` 只发推广短链文字；需要图片时可用系统把短链转成二维码，或改用美团/闪购红包
