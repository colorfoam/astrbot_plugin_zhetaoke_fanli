📖 使用说明

  • 数据来源：折淘客开放平台 API（zhetaoke.com）。插件按配置的间隔自动轮询美团订单、联盟全平台订单与淘宝订单明细并入库。
  • 覆盖平台：美团外卖/闪购、饿了么（淘宝闪购）、淘宝、抖音、京东、拼多多、唯品会等（联盟订单接口覆盖）。
  • 返利归因：美团/饿了么走 customer_id，抖音走 external_info，淘宝走 external_id，均为 11 位内数字，与用户绑定 ID 一致即归档到该用户名下。
  • 聊天指令：绑定、我的返利、查订单、美团红包、闪购红包、淘宝转链 内容、抖音转链 内容、搜抖音 关键词、同步订单(管理员)。
  • 限速提醒：折淘客禁止多线程高频调用，轮询间隔请勿低于 2 分钟；淘宝订单接口单次最多查 3 小时。
  • 前置条件：必须在折淘客后台完成淘宝账号授权（获得 SID），且订单必须由折淘客转链接口产生才能被查到。
  • 访问控制：如配置了 WebUI 访问令牌，请在本页地址后追加 ?token=你的令牌。
