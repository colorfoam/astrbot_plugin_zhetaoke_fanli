📖 使用说明

  • 数据来源：折淘客开放平台 API。插件按配置间隔自动轮询美团订单、联盟全平台订单与淘宝订单明细并入库。
  • 覆盖平台：美团外卖/闪购、饿了么（淘宝闪购）、淘宝、抖音、京东、拼多多、唯品会等。
  • 返利归因：美团/饿了么走 customer_id，抖音走 external_info，淘宝走 external_id，与用户绑定 ID 一致即归档。
  • 聊天指令（与插件实际注册的指令保持同步）：
    加载中…
  • 限速提醒：折淘客禁止多线程高频调用，轮询间隔请勿低于 2 分钟；淘宝订单接口单次最多查 3 小时。
  • 前置条件：需在折淘客后台完成淘宝账号授权（SID），且订单必须由折淘客转链接口产生。
